# 🐢 TurtleCross — A Python Turtle Game

A fun and simple **arcade-style game** built with Python’s `turtle` module.  
Help your turtle cross the road without getting hit by cars!  
Each time you make it to the other side, the level gets faster and harder. 🚗💨

---

## ✨ Features
- 🎮 Player-controlled turtle using arrow keys only (Up Arrow)
- 🚘 Randomly generated cars moving across the screen  
- 🏁 Level-up system (each level = higher speed)  
- 💥 Game Over screen when the turtle gets hit  
- 🧠 Clean object-oriented design with multiple classes  

---

## 🎮 Controls
| Action | Key |
|:-------:|:----:|
| Move Up | `↑` (Up Arrow) |
| Quit Game | Close the window |

---

## 📦 Requirements
- Python **3.8+**
- Uses only the built-in `turtle`, `time`, and `random` modules — **no external libraries**
